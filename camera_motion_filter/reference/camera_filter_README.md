# 相机过滤：并集 + ≤1.5 秒 infill（含首尾）

当前规则版本 `union_infill_v1`，`infill_edges=true`。计算与网页更新于 2026-09-16。

1. 角速度 >19°/s、平移速度 >0.40/s 分别生成布尔 invalid 区间。
2. 先取两项区间并集，同一点不重复计数。
3. 找到并集后的所有连续合格段，持续时间按采样边界 t[end]-t[start] 计算。≤1.5 秒全部填为 invalid，**包括首尾**；>1.5 秒保留。整个相机覆盖区间均合格且 ≤1.5 秒时也全部填充。
4. 填充后的 invalid 点数 / 全部相邻采样帧区间数 >50% 时过滤。恰好50%保留。此前 clip <1 秒跳过规则保留。

沿用原始约4 FPS及末帧采样；速度按真实 Δt 计算，infill 长度按秒判断，最终比例仍按点数统计，不改为时间加权或曲线面积积分。相机覆盖区间从首帧至末帧时间戳，不虚构末帧后的区间。

网页面积图四行依次为角速度、平移、原始并集、infill后并集。橙色是原始 invalid，紫色是新增填充，深色是合格。点击定位视频。两种相机使用相同算法。
